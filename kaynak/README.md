# Kaynak sesler

Hazırlanmamış ham sesler. `tools/prep_sounds.py` bunlardan `sounds/` klasörünü üretir.

- `hcr/`: Geliştirici tarafından sağlanan efekt paketi (tıklama, altın, satın alma, yakıt, turbo, süper şarj, motor döngüleri). Telif hakkı özgün sahibine ait olabilir; yalnızca kişisel/proje içi kullanım için eklendi.
- `bosyol/`: Eski Boş Yol projesinden alınan ortam sesleri. Kaynaklar: Moodist (CC0 ve Pixabay İçerik Lisansı), pmndrs/racing-game (CC0), Bruno Simon folio-2019 (MIT).
